# Capital Media Systems website content model

Status: **Proposed**

The first implementation may encode this content in HTML or structured local files. A database or CMS is not required.

## Page

- Stable path
- Navigation label
- Browser title
- Meta description
- Eyebrow
- Page heading
- Introductory copy
- Ordered content sections
- Optional social image
- Truth-review date

## Content section

- Section identifier
- Optional eyebrow
- Heading
- Body content
- Layout variant
- Optional media reference
- Optional call to action
- Truth status: accepted, proposed, or open

## Product

- Formal name
- Descriptor
- Status: current or archived
- Approved date range, if known
- Short description
- Long description
- Capability statements
- Product mark reference
- Availability language
- Truth status

## Timeline entry

- Display year or period
- Heading
- Description
- Related product, if any
- Source or approval note
- Truth status

## Person

- Name
- Role
- Biography
- Portrait
- Alternative text
- Display order
- Approval status

No real person should be represented until verified information and usage permission are supplied.

## Contact method

- Type: email, telephone, mailing address, or business hours
- Label
- Display value
- Link value when applicable
- Public/private classification
- Verification date
- Approval status

## Media asset

- Stable local path
- Category
- Source master
- Width and height
- Alternative text
- Caption
- Credit or permission note
- Truth status

## Claim

Maintain an editorial claim register for facts that could mislead if wrong:

- Claim text
- Page and section
- Category: company, product, compatibility, commercial, customer, legal, or performance
- Source
- Status: accepted, proposed, open, or rejected
- Approval date
- Reviewer

## Placeholder

- Required aspect ratio
- Intended subject
- Art direction
- Caption
- Replacement requirement

Placeholders must remain visibly intentional and must never resemble missing or broken content.
